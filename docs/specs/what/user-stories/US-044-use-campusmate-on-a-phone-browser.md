# US-044 — Use CampusMate on a phone browser

> **What this document is:** the capability we want and how we will know it works.
> **What this document is NOT:** how it is built. Implementation approach is the team's call — see `docs/specs/how/`.

## Story

As a student,
I want to use CampusMate in my phone's browser,
so that I can check my plan and log attendance away from a computer.

## Why this matters

Students check timetables and log attendance in class, where they only have a phone. The synopsis promises desktop and mobile browsers (§2.6).

## Acceptance criteria

- [ ] Every screen is usable at 375 px wide with no horizontal page scrolling.
- [ ] All buttons and inputs are at least 44 by 44 px.
- [ ] Every user story's main flow works in current Chrome on Android and Safari on iOS.
- [ ] Forms stay usable while the on-screen keyboard is open.

## Out of scope

A native mobile app and offline use (synopsis §10).

## Evidence it exists today

Not built.
