# US-021 — Browse, search and delete notes

> **What this document is:** the capability we want and how we will know it works.
> **What this document is NOT:** how it is built. Implementation approach is the team's call — see `docs/specs/how/`.

## Story

As a student,
I want to browse my notes by subject, search them by title and delete ones I no longer need,
so that I can find material quickly.

## Why this matters

Scattered, unsearchable notes are one of the problems in synopsis §2.3. A list that only grows becomes the same mess inside CampusMate.

## Acceptance criteria

- [ ] The notes screen lists notes with title, subject and upload date, newest first.
- [ ] The list can be filtered by subject.
- [ ] Searching by title matches any part of the title, ignoring case.
- [ ] A note's title defaults to the uploaded file name and can be edited.
- [ ] Deleting a note after confirmation removes it with its summary, quiz, quiz attempts and any stored file.

## Out of scope

Searching inside note contents, folders and tags.

## Evidence it exists today

Not built.
