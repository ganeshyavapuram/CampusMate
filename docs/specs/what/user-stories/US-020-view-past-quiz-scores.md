# US-020 — View past quiz scores

> **What this document is:** the capability we want and how we will know it works.
> **What this document is NOT:** how it is built. Implementation approach is the team's call — see `docs/specs/how/`.

## Story

As a student,
I want to see my previous scores for a note's quiz,
so that I can tell whether my understanding is improving.

## Why this matters

A single score shows how a student did once; repeated attempts show learning. Without history, retaking a quiz gives no sense of progress.

## Acceptance criteria

- [ ] The note screen lists quiz attempts newest first, each with its date and score.
- [ ] The best score is shown separately.
- [ ] A note with no attempts shows "No attempts yet".

## Out of scope

Charts of scores across subjects or over time.

## Evidence it exists today

Not built.
