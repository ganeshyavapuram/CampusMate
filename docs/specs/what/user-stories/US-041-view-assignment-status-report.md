# US-041 — View assignment status report

> **What this document is:** the capability we want and how we will know it works.
> **What this document is NOT:** how it is built. Implementation approach is the team's call — see `docs/specs/how/`.

## Story

As a student,
I want a report of pending, completed and overdue assignments by subject,
so that I can see where I'm falling behind.

## Why this matters

Seeing completion by subject shows which courses are slipping, which a flat list hides.

## Acceptance criteria

- [ ] The report shows, per subject, counts of pending, completed and overdue assignments.
- [ ] The report can be filtered to one subject.
- [ ] The report can be downloaded as CSV and printed from the browser.

## Out of scope

Charts.

## Evidence it exists today

Not built.
