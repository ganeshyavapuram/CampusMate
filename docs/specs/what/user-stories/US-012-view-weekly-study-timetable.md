# US-012 — View weekly study timetable

> **What this document is:** the capability we want and how we will know it works.
> **What this document is NOT:** how it is built. Implementation approach is the team's call — see `docs/specs/how/`.

## Story

As a student,
I want to see my study sessions laid out by week,
so that I know what to study each day.

## Why this matters

A generated plan is only useful if the student can see it in a form that matches how they think about their week. The synopsis lists a Timetable View screen but no story for it.

## Acceptance criteria

- [ ] The timetable shows Monday to Sunday of the current week, with each session's subject and duration under its day.
- [ ] The student can move to the previous and next week.
- [ ] Planned, completed and missed sessions are distinguishable by both colour and a text label.
- [ ] Today's column is highlighted.
- [ ] At a screen width of 375 px the week is readable without horizontal page scrolling.

## Out of scope

Month view and exporting to an external calendar.
