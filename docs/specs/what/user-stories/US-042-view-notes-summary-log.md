# US-042 — View notes summary log

> **What this document is:** the capability we want and how we will know it works.
> **What this document is NOT:** how it is built. Implementation approach is the team's call — see `docs/specs/how/`.

## Story

As a student,
I want a log of my uploaded notes and their summaries,
so that I can revise from summaries across all subjects in one place.

## Why this matters

Summaries are spread across individual note pages. A combined log works as a revision sheet before exams.

## Acceptance criteria

- [ ] The log lists every note with subject, title, upload date, the first 200 characters of its summary, and its best quiz score.
- [ ] The log can be filtered by subject.
- [ ] The log can be downloaded as CSV and printed from the browser.

## Out of scope

Combining several summaries into one AI-written document.

## Evidence it exists today

Not built.
