# US-038 — View profile and rewards

> **What this document is:** the capability we want and how we will know it works.
> **What this document is NOT:** how it is built. Implementation approach is the team's call — see `docs/specs/how/`.

## Story

As a student,
I want a profile page with my XP, level, streak and badges,
so that I can see everything I've achieved in one place.

## Why this matters

Rewards only motivate if they're visible. The synopsis lists a Profile and Rewards screen with no story behind it.

## Acceptance criteria

- [ ] The profile shows display name, email, XP total, level, current streak, and earned badges with the date each was earned.
- [ ] Badges not yet earned appear greyed out with the condition for unlocking them.
- [ ] The profile shows only the signed-in student's information.

## Out of scope

Public profiles and leaderboards (synopsis §8).

## Evidence it exists today

Not built.
