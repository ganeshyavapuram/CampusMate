# US-036 — Unlock badges

> **What this document is:** the capability we want and how we will know it works.
> **What this document is NOT:** how it is built. Implementation approach is the team's call — see `docs/specs/how/`.

## Story

As a student,
I want to unlock badges for milestones,
so that I have goals beyond the daily routine.

## Why this matters

Badges give medium-term goals that XP alone doesn't. The synopsis names only one example (a 7-day streak).

## Acceptance criteria

- [ ] Reaching a 7-day streak unlocks the "7-Day Streak" badge.
- [ ] Each badge is earned at most once per student and stores the date it was earned.
- [ ] When a badge unlocks, a short on-screen message names it.
- [ ] The full badge list and the conditions for each are defined before this story is built.

## Out of scope

Badges awarded by teachers, and sharing badges.

## Evidence it exists today

Not built.

## Open questions

Which badges beyond "7-Day Streak" should exist (for example first completed assignment, 10 assignments completed, a perfect quiz score)?
