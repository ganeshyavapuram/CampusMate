# US-040 — View attendance report

> **What this document is:** the capability we want and how we will know it works.
> **What this document is NOT:** how it is built. Implementation approach is the team's call — see `docs/specs/how/`.

## Story

As a student,
I want an attendance report across all my subjects,
so that I can review my attendance in one place or share it with my guide.

## Why this matters

The dashboard shows a snapshot; a report gives the full picture with counts that a student can print or share.

## Acceptance criteria

- [ ] The report shows, per subject, classes held, classes attended, percentage, and status (OK, At risk or Below 75%).
- [ ] The figures match the attendance screen exactly.
- [ ] The report can be downloaded as CSV and printed from the browser.

## Out of scope

Date-range filters.

## Evidence it exists today

Not built.
